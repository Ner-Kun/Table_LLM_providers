    LLM Providers Table

    What is this for?

    Here you will find free, freemium, and paid providers, that provide access to large language models. It includes limits, registration requirements, the ability to quickly copy the Base URL, and direct links for registration/getting an API key.

    Help tablet! Share it!

    The more people who use it, the more motivated I'll be to update it, add new providers, and keep everything up to date. Post a link to the table in chat, in repo, in comments, or on Discord server - anywhere 🙏

    Warning

    Providers change limits, models, and sometimes even die... I am just one person, but there are many providers, so I don't always have time to update table.
    If there are any discrepancies with the real situation at the provider, please inform me! Via on Telegram or DS - Ner_Kun.

    Friends, if you, like me, roleplay with AI in languages other than English and lorebooks don't work or you translate them yourself, check out my project Lorebook Gemini Translator (It works not only with Gemini).

    How to use the table

    Main fields

    • Base URL: A ready-to-use address for connecting to the API in your code or application.
    • Models: A list of key large language models available in the service. The 🌐 link usually leads to the full list.
    • Limits: API usage restrictions. RPM - requests per minute, RPH - per hour, RPD - per day.
    • Reliability: The author's subjective rating of the service's stability on a 5-star scale.

    Icon legend

    • Navigation:

    • 🌐 - clickable link to the corresponding page (registration, getting a key, viewing models).

    • Testing status:

    • ✅ - tested by the author.
    • ❌ - service has not been tested yet.

    • ⏳ - in the process of testing.

    • Registration requirements:

    • ✉️ - email is required.
    • 🔑 - standard registration on the website.
    • 📱 - requires phone number verification.
    • 💳 - linking a bank card is required.
    • 📝❗ - registration has special conditions (e.g., only via a GitHub account).
