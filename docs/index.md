# LLM Providers Table

!!! info "What is this for?"
    Here you will find free, freemium, and paid providers, that provide access to large language models. It includes limits, registration requirements, the ability to quickly copy the Base URL, and direct links for registration/getting an API key.

!!! tip "Help tablet! Share it!"
    The more people who use it, the more motivated I'll be to update it, add new providers, and keep everything up to date.
    **Post a link to the table in chat, in repo, in comments, or on Discord server - anywhere 🙏**

!!! warning "Relevance"
    Providers change limits, models, and sometimes even die...
    *I am just one person, but there are many providers*, so I don't always have time to update table.  
    If there are any discrepancies with the real situation at the provider, **please inform me!** Via on [Telegram](https://t.me/ner_kun_off) or [DS](https://discord.gg/mqch59Bbmw) - Ner_Kun.

!!! note "For roleplayers"
    Friends, if you, like me, roleplay with AI in languages other than English and lorebooks don't work or you translate them yourself, check out my project [Lorebook Gemini Translator](https://github.com/Ner-Kun/Lorebook-Gemini-Translator) (It works not only with Gemini).

## How to use the table

Click or tap the badges and requirement icons to see short explanations.

### Main fields

* **Base URL**: A ready-to-use address for connecting to the API in your code or application.
* **Models**: A list of key large language models available in the service. The globe icon usually leads to the full list. (You can also look at the list of all models from the provider, but the prices there do not reflect the provider's pricing and model capabilities; the information there is from official providers)
* **Limits**: API usage restrictions. RPM - requests per minute, RPH - per hour, RPD - per day, etc.
* **Provider badges**: Service status and testing status are shown next to the provider name.

## Categories

* [**Freemium providers**](freemium.md) - providers that are not completely free, but provide credits/money to your account upon registration.
* [**Free providers**](free.md) - providers that offer access to models absolutely for free.
* [**Paid**](paid.md) - services that require payment or operate on a credit-based system.
* [**Warning**](caution.md) - providers with unconfirmed concerns, suspicious behavior, or trust issues that don't rise to "dangerous" level.
* [**Dangerous / Not Recommended**](dangerous.md) - providers with serious community concerns or trust issues. (It's empty for now)
