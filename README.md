## How to use the table

### Main fields

* **Base URL**: A ready-to-use address for connecting to the API in your code or application.
* **Models**: A list of key large language models available in the service. The 🌐 link usually leads to the full list.
* **Limits**: API usage restrictions. RPM - requests per minute, RPH - per hour, RPD - per day.
* **Reliability**: The author's subjective rating of the service's stability on a 5-star scale.

### Icon legend

* **Navigation**:
  * 🌐 - clickable link to the corresponding page (registration, getting a key, viewing models).

* **Testing status**:
  * ✅ - tested by the author.
  * ❌ - service has not been tested yet.
  * ⏳ - in the process of testing.

* **Registration requirements**:
  * ✉️ - email is required.
  * 🔑 - standard registration on the website.
  * 📱 - requires phone number verification.
  * 💳 - linking a bank card is required.
  * 📝❗ - registration has special conditions (e.g., only via a GitHub account).
